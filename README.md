# EKUT — E-Kantin UT Self Ordering & CRM System

EKUT (E-Kantin UT) is a self-ordering and CRM system designed to support
food and beverage ordering, tenant management, rental payment monitoring,
revenue tracking, and reporting within the Universitas Terbuka canteen
environment.

## Project Status

Currently in development.

## Main Actors

- Customer
- Tenant
- Admin

## Main Features

### Customer
- View available tenants
- View menu
- Add items to cart
- Create order
- Make payment
- View order receipt

### Tenant
- Manage incoming orders
- Update order status
- Manage menu and quantity
- View sales history
- View daily revenue
- Manage rental payment

### Admin
- Register and manage tenants
- Monitor tenant rental payment status
- Monitor daily revenue
- Filter revenue by tenant and date
- Export reports
